# NSS — National Sports School Management Application

A management application for a national sports school: manage students, staff, sports, and schedules from a single web app.

## Stack

Built with **Lovable** — React + TypeScript + Vite, styled with Tailwind CSS and the shadcn/ui component set.

## Getting started

```bash
npm install
npm run dev      # dev server
npm run build    # production build
```

## Development

This project was scaffolded with [Lovable](https://lovable.dev) and can be edited either in the Lovable editor or locally in any IDE. If you work locally, you need Node.js and npm installed.
